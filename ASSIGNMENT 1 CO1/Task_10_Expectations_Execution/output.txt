Important:
- Integer paise totals are exact as long as long long does not overflow. A long long is required because 3,000,000 * 1234 = 3,702,000,000 paise, greater than INT_MAX.
- double uses binary floating point; the exact difference may display as 0.00 at two decimal places even if a tiny representation error exists internally. Use setprecision(17) to inspect it.
- The source intentionally labels the int result as unreliable: signed integer overflow is undefined behaviour in C++, so do not rely on a particular number.
- Each addition is O(1). int is typically 4 bytes; long long and double typically 8 bytes. int risks overflow, long long risks overflow only at much larger totals, and double can lose exact cent-level precision for sufficiently large values.
- Compile with -Wall -Wextra. Warnings depend on compiler/version; common warnings include signed/unsigned comparisons and unused variables, not necessarily a warning for every possible overflow.
